Vragenbibliotheek

Dit is je tekstbibliotheek. Je hoeft hier niets “aan” te zetten voor Forms: Copilot/Forms bepaalt welke vragen gesteld worden. Na Excel-import zet de app automatisch aan wat in het bestand zat. De schakelaar hier is alleen: tonen in het sociogram.

Klas

Leerlingenlijst voor Forms-opties en het sociogram. Spelling moet overeenkomen met de namen in Forms.

Huidige lijst

    Uitdelen (zonder Forms-handwerk)

    Geen database en geen Copilot-formulier bouwen. Elke leerling krijgt een persoonlijke code en vult alleen het eigen tabblad / eigen webformulier in. Jij houdt het codeblad geheim.

    1. Pakket maken

    Aanbevolen: HTML-invulpagina (Chromebook-vriendelijk) — leerling opent bestand, typt code, downloadt antwoorden-CSV.
    Excel: één .xls met tabblad per code (deel via OneDrive). Let op: Excel kan andere tabbladen technisch niet verbergen; privacy = code niet delen.

    2. Antwoorden importeren

    Upload één of meer antwoord-XXXX.csv (uit HTML), of het ingevulde Excel-bestand (.xls), of plak CSV.
