SOCIOGRAM — GitHub Pages (nu) + Cloudflare login (later)
=======================================================

FASE 1 — Website op GitHub (GEEN login)
---------------------------------------
1. Push deze repo naar GitHub (bijv. sociogram-app).
2. Settings → Pages → Build and deployment → Source: GitHub Actions
   (de workflow .github/workflows/pages.yml doet de rest na push naar main).
3. Site-URL wordt ongeveer:
   https://<jouw-github-user>.github.io/sociogram-app/
4. Mentoren openen die link. Data staat in localStorage van hun browser
   (per apparaat). Inloggen / gedeelde cloud komt in fase 2.

Lokaal testen: open index.html in Chrome, of live via Pages-URL.
